Juego del TesoroTreasure hunt

Te mueves por un mapa de agua y tierra hasta encontrar el tesoro. Cada partida genera un mapa nuevo.You move across a map of water and land until you find the treasure. Every game generates a new map.

  1. El mapaThe mapUna cuadrícula con un 60 % de agua y un 40 % de tierra. El juego se asegura de que siempre hay un camino por tierra hasta el tesoro.A grid that is 60% water and 40% land. The game makes sure there is always a land path to the treasure.
  2. MuéveteMoveSólo puedes pisar tierra; el agua no se cruza.You can only walk on land; water cannot be crossed.
  3. GanaWinAl encontrar el tesoro te dice cuántos movimientos has hecho.When you find the treasure it tells you how many moves you made.

Ahorcado de futbolistasFootball hangman

El ahorcado de toda la vida, pero las palabras son nombres de futbolistas. Vas probando letras hasta adivinar el jugador antes de quedarte sin intentos.Classic hangman, but the words are football players' names. You guess letters until you find the player before running out of tries.

Árbol de NavidadChristmas tree

Dibuja un árbol de Navidad en la terminal con bucles y colores ANSI. Un ejercicio pequeño para practicar bucles anidados.Draws a Christmas tree in the terminal with loops and ANSI colours. A small exercise to practise nested loops.

EjecutarlosRun them

Los tres funcionan igual: necesitas Java 17 o superior y una terminal.All three work the same way: you need Java 17 or newer and a terminal.

javac Main.java java Main

Si los colores salen como códigos raros, usa una terminal que entienda ANSI, como Windows Terminal o la de IntelliJ.If colours show up as strange codes, use a terminal that supports ANSI, such as Windows Terminal or IntelliJ's.
